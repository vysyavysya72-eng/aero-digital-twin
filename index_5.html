10 / SYSTEM STATUS & DATA PROVENANCE

WHAT'S LIVE, WHAT'S SIMULATED.

Kept visible for judges — this is engineering maturity, not a gap.

Live Sensor Stream

SIMULATED

Telemetry is generated client-side on a deterministic pattern. No CAN/ECU hardware link is connected in this build — architecture is designed to accept one.

Diagnostic Model

RULE-BASED

Anomaly score and RUL are computed from threshold/physics rules over live synthetic signals, not a trained ML model. POC decision-support layer pending model swap-in.

Mission Replay

SCRIPTED

Replay timeline is interactive but runs a scripted mission log, not an uploaded flight dataset. Schema is ready to ingest a real CSV mission log.

Extended Telemetry & Report

ACTIVE

New gauges, 4 new fault profiles, efficiency trend, and the mission report button are functional client-side logic.
