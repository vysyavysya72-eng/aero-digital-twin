# AeroTwin Command Center

AeroTwin Command Center is an AI-powered Digital Twin and predictive health monitoring system designed for aero piston engines used in MALE UAVs. The system helps monitor engine health in real time, detect abnormal conditions, track degradation, predict potential faults, and support Remaining Useful Life (RUL) estimation. It provides a centralized interface for visualizing engine parameters, analyzing health status, and supporting safer and more reliable UAV operations.

## Key Features

- Real-time engine health monitoring
- Anomaly and fault detection
- Engine degradation tracking
- Predictive maintenance support
- Remaining Useful Life (RUL) estimation
- Mission-wise engine performance analysis
- Interactive command center dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- AI/ML-based predictive analysis

## Project Goal

The goal of AeroTwin Command Center is to improve UAV engine reliability and safety by combining real-time sensor data, physics-based models, and AI/ML techniques for intelligent engine health monitoring and prediction.
